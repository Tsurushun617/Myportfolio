# テーマカラーの選定背景と意味

- **確定日**：2026-08-26
- **出典**：日本の伝統色 <https://nipponcolors.com/>（hex は同サイトの値をそのまま使用）
- **実装箇所**：`assets/css/style.css` の `:root`

このドキュメントは「なぜこの色なのか」を後から再調査せずに済むように残している。色を変更する際は、まずここを読むこと。

---

## 背景 — なぜ青から緑に変えたか

サイトのロゴは **sprout（苗）のアイコン**である。にもかかわらず、変更前のテーマカラーは青 `#4d96ff` で、ロゴの意味と色が噛み合っていなかった。

色の指針は、サイト主（鶴岡）の自己像そのものから引いている。

> 植物のように力強く、粘り強くありたい。
> 菌根菌ネットワークを周囲に与えるような存在でありたい。
> 動物は他から栄養を摂取するが、植物は自分で養分を生成する。そういう存在になりたい。

このリニューアルでは、上記を色に翻訳することと、**アクセシビリティの既存問題の解消**を同時に行った。変更前は `--accent`（2.95:1）も `--accent-2`（2.78:1）も、白背景で WCAG AA の 4.5:1 に届いていなかった。

---

## パレット全体の構造 — 植物の姿をそのまま写す

色はばらばらの寄せ集めではなく、**ひとつの植物の姿**になるよう組んである。

```
        山吹 #ffb11b ── 光（自ら養分を生成する）
             ↑ 光合成
   ┌──────────────────────────────┐
   │  常磐 #1b813e   葉・幹（力強く、粘り強く）      │
   │  若竹 #5dac81   若い芽（成長・しなやかさ）      │  地上
   │  白緑 #dcefe3   葉の淡い面（セクション背景）    │
   ├──────────────────────────────┤
   │  鳥の子 #f0e9db  土壌（菌根菌ネットワーク）     │  地下
   └──────────────────────────────┘
```

- **地上（緑）と地下（土色）**で淡色セクションを2種類に分けている。植物は葉だけでは成立せず、根と土中のネットワークがあって初めて立つ
- **ヒーロー見出しのグラデーションが `常磐 → 山吹`**、つまり葉が光に変わる方向。パレット全体の主題（光合成）をここ1箇所で言い切っている
- 差し色の山吹をサイト全体に散らすことで、「他から摂取するのではなく、自分で光を養分に変える」という自己像がページ全体に反復される

## 各色の由来と選定理由

### 常磐（ときわ）`#1b813e` — メインカラー `--accent`

- **語源**：「常磐」は本来「常に変わらない岩」の意。転じて永久不変を指す
- **常磐木（ときわぎ）** ＝常緑樹。松・杉のように、冬も葉を落とさない木。その葉の色が常磐色
- **文化的な位置づけ**：平安期から「永遠・不変・繁栄」を表す吉祥の色として扱われてきた
- **なぜ選んだか**：「**力強く、粘り強く**ありたい」に最も正確に対応する。落葉せず、冬を越え、色を変えない木の緑。一時的な鮮やかさではなく持続する強さを表す
- **実務上の理由**：白背景で 4.93:1 と AA を満たしつつ、暗くなりすぎず鮮やかさを保つ数少ない伝統緑。「白・淡色ベース＋遊び心」というサイトのトーンを壊さない

### 若竹（わかたけ）`#5dac81` — `--accent-light`

- **語源**：その年に生えた若い竹の色
- **性質**：竹は成長が極めて速く、しなやかで、強風でもしなって折れない
- **なぜ選んだか**：ロゴが**苗**である以上、パレットに「若さ・伸びる途中」を表す色が要る。常磐（成熟）と若竹（成長）が並ぶことで、育つ過程そのものが表現される
- **使いどころ**：スキルメーターと MBTI バーのグラデーション。`常磐 → 若竹` は「濃い緑から若い芽へ」の方向で、伸びていく動きと一致する

### 白緑（びゃくろく）のティント `#dcefe3` — `--leaf`

- **語源**：岩絵具の**緑青（ろくしょう）を細かく砕くほど白っぽくなる**。その最も淡い段階が「白緑」
- **文化的な位置づけ**：日本画・仏画の彩色に使われた顔料の色名
- **なぜ選んだか**：セクション背景は面積が広いため、原色の `#a8d8b9` では強すぎる。白緑はもともと「砕いて淡くした緑」であり、**ティント（白と混ぜて淡くする）という操作そのものが色名の由来と一致する**
- **調整**：60% ティント。変更前の `--mint`（輝度 0.8275）に対し 0.8249 と、ほぼ同一の明るさに揃えてある

### 鳥の子（とりのこ）のティント `#f0e9db` — `--soil`

- **語源**：**鶏卵の殻の色**。淡い黄みがかった白
- **もうひとつの意味**：雁皮（がんぴ）を原料とした最高級和紙「鳥の子紙」の色名でもある
- **なぜ選んだか**：「**菌根菌ネットワークを周囲に与える**」を表す場所として、地下＝土壌の色が要る。菌根菌は土の中で植物同士をつなぐ。緑（地上）と対になる淡いベージュを置くことで、サイトが地上と地下を行き来する構造になる
- **補足**：鳥の子紙は「何かが書き記される下地」でもあり、他者に養分を与える基盤という含意とも重なる
- **調整**：60% ティント。変更前の `--pink`（輝度 0.8294）に対し 0.8192

### 山吹（やまぶき）`#ffb11b` — 差し色 `--accent-2`

- **語源**：ヤマブキの花の色。晩春に咲く鮮やかな黄
- **もうひとつの意味**：**黄金の代名詞**。小判の色を「山吹色」と呼んだ
- **なぜ選んだか**：「**動物は他から栄養を摂取するが、植物は自分で養分を生成する**」——その養分の源である**光**を表す。緑の補色側にあるため差し色として最もよく効く
- **二重の含意**：山吹色は同時に「価値を生み出すこと」の色でもある。自ら価値を生成するという自己像と、光合成の比喩が同じ色に重なる

### 山吹の濃色 `#8c610f` — 文字用 `--accent-2-ink`

- 山吹をそのまま文字に使うと白背景で 1.82:1 と読めない。明度を落とした派生色を**文字専用トークン**として分離した
- 色相は山吹のまま保持しているため、装飾の山吹と並んでも同系色として自然に見える
- 領域としては「黄土」「金茶」に近い、土に還った金の色

---

## 山吹の使い分けルール（重要）

`--accent-2`（`#ffb11b`）は**文字に使わないこと**。白背景で 1.82:1 しかない。

| 用途 | 使うトークン | 該当箇所 |
|---|---|---|
| **装飾**（背景・罫線・グラデーション） | `--accent-2` | `.section-head .en::before` / `.nav__link::after` / `.hero__title .grad` / `.scroll-cue::after` / `.mbti-trait` の `border-left` / `.blob--3` |
| **文字** | `--accent-2-ink` | `.mbti__eyebrow` / `.mbti-trait__no` / `.value__no` |

## 選ばなかった色と、その理由

| 検討した色 | hex | 見送った理由 |
|---|---|---|
| 木賊（とくさ） | `#2d6d4b` | コントラストは最良（6.18:1）だが暗く渋く、「苗の若さ」が出ない。**淡色セクション上でも完全に AA を満たしたい場合の差し替え候補として残す** |
| 緑（みどり） | `#227d51` | 青みが強く「成木・深い森」の印象。苗のイメージからやや遠い |
| 松葉（まつば） | `#42602d` | 常緑という意味では適合するが黄み・暗さが強く、明るいトーンから離れすぎる |
| 麹塵（きくじん） | `#b1b479` | 伝統色で唯一「菌」を名に持ち菌根菌に直結するが、緑と色相が近く差し色として弱い。土壌の色 `--soil` が同じ役割を担うため見送り |
| 珊瑚朱（さんごしゅ） | `#f17c67` | 変更前の珊瑚色に最も近く変更は最小で済むが、「光合成」の物語に乗らない |

### 既知の制約

**淡色セクション（`--leaf` / `--soil`）の上に載るリンク文字は 4.11:1** で、AA の 4.5:1 にわずかに届かない。変更前（青 × 淡青で約 2.5:1）からは大幅な改善だが、完全ではない。

淡色セクション内でも完全な AA を満たしたい場合は、メインカラーを**木賊 `#2d6d4b`**（淡色上で 5.2:1）に差し替える。**変更は `--accent` の1行のみ**で済む。今回は「苗の若さ・鮮やかさ」を優先して常磐を採用した。

なお `--muted`（3.9:1）が淡色セクション上で AA に届かない点は、今回の変更前後で変わっていない。
